# HW7 CI/CD Deployment

## Описание стратегии

В проекте реализована стратегия Blue-Green Deployment.

Используются два окружения:
- blue — стабильная версия сервиса;
- green — новая версия сервиса.

Для развертывания используются файлы:
- `Dockerfile`
- `.github/workflows/deploy.yml`
- `docker-compose-blue.yaml`
- `docker-compose-green.yaml`
- `nginx.conf`

Маршрутизация трафика выполняется через Nginx.  
Сначала трафик направляется на стабильную версию blue. После проверки новой версии через `/health` трафик может быть переключен на green. При ошибках выполняется rollback на blue-версию.

## Шаги запуска

1. Собрать Docker-образ приложения.
2. Запустить blue- и green-версии через соответствующие docker-compose файлы.
3. Настроить Nginx для маршрутизации трафика.
4. Выполнить проверку `/health`.
5. Выполнить тестовый запрос к `/predict`.
6. При необходимости переключить трафик на новую версию или вернуть его на стабильную.

## Проверка результата

Для проверки использовались запросы:

```bash
curl http://127.0.0.1:8000/health
curl -X POST http://127.0.0.1:8000/predict -H "Content-Type: application/json" -d '{"x": }'
```

Результаты:
- `/health` → `{"status":"ok"}`
- `/predict` → `{"input":[1.0,2.0,3.0],"prediction":6.0}`
